<h1>Project name: Keen Keeper</h1>
<p> Description: On this website, we can select any friend and contact them by call, text, or video on the friend-detail-page. Contact history will be saved in timeline-page, we can also filter the history. We can also see a py-chart in the status-page </p>

<h2>Technologies:</h2>
1. React,<br/>
2. Tailwind CSS,<br/>
3. React-Router,<br/>
4. Context-API,<br/>
5. Custom Hooks etc

<h2>Features:</h2>
1. Used custom hooks to fetch data to reduce code.<br/>
2. Used the Context API to access the called-array from anywhere.<br/>
3. After clicking any Contect button i have added some extra data into the friend object. Which helped me to differentiate the array. It's used for filtering and py-chart<br/>
